# Lander
Lander Study Project Repo

Here's my Godot game called Lander. Made in Godot 4.6.2 initially and later ported over to 4.7.2
It's written in GDScript as a study project to learn the basics of the programming language and overall work in Godot.
It's based on a tutorial project from a Godot course i'm following with a few small changes here and there.
Had some good fun with this one and there are a few more things to sort out like the planet texture displaying incorectly.
